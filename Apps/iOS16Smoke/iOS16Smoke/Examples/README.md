# Example SVGs

Drop `.svg` files in this folder to preview them in the iOS 16 smoke app.

1. Copy files here.
2. Rebuild and run `iOS16Smoke`.
3. Open **Examples** — every `.svg` in this folder is rendered.

These files are gitignored. Do not commit customer artwork, production labels, or other local fixtures. The gallery loads whatever is in the app bundle, so a rebuild is required after adding or removing files.
